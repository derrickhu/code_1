村民三阶立绘 · 出图 + 质检规范 v3
================================

v2 的装备升级路线保留。v3 改流水线：禁止三阶对照条再切开。
电锯哥 evo2 就是反面教材：锯子被左边缘切短，右下角飘着 evo3 的锯尖。

一、只出单人单张
----------------
- 一张图只许一个人、一个阶。3:4 竖图。
- 禁止 16:9 三连拍再切。隔壁人的锤子、锯、狗会漏进格子。
- 参考图只供这张脸和衣服，不要把参考图的构图、裁切、另一阶的道具带进来。

二、安全框（生图时就要满足，后处理救不回来）
--------------------------------
- 人物 + 全部道具完整落在画布里。
- 四边约 12% 白边。头上的阀、手里的锯条/锤头/管、脚尖、背后的罐，离边都要看得见空。
- 横道具往身上收。禁止贴边、出框、从画外伸进来半截。
- NO TEXT, no labels, no second character, no floating leftover props.

三、装备升级（同 v2）
--------------------
一阶过日子最窄；二阶 scrap 变宽；三阶能打：头上有件、背后有件、手里换更凶的家伙。

四、机器质检（不过线不准进游戏）
--------------------------------
对去底后的 PNG：
1. CLIP：四边各 8px 带里不得有 alpha>=16 的实心。贴边 = 被切或切串格。
2. LEAK：面积 >= 80 像素的连通块不得多于 1 个。右下角飘锯尖就是第二块。
3. EMPTY：不透明面积至少占画布 8%。
4. MARGIN：包围盒四边相对画布至少留 16px（去底灰尘按 alpha>=16）。

不过的重出这一张，不要整表蒙混过关。

----------

2. rembg isnet-anime（只处理本批目录）
3. alpha>=16 取盒，留 24px
4. 跑质检，全过再拷 assets/images/hero/{id}_evo{n}.png
5. 更新 portraitFit.ts
