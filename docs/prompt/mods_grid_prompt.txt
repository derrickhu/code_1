Style: same sticker-chibi world as the villager sheet. Fat comic outlines, TWO-tone cel shade, 6-8 colors, ONE highlight blob per big shape. Chunky readable silhouette, object centered, slight 3/4 tilt so it reads as a thing you can pick up. NO texture noise, NO glow, NO shadows on the backdrop.
NO TEXT, no labels, no letters, no numbers, no watermarks.
