Enemy style revision: COLOR + DIFFICULTY must read at a glance.
Keep the chubby pulp-chrome family from the reference. Pale gray panels, fat outlines.
NO TEXT, no labels, no letters, no numbers, no watermarks.

Visual bible (must obey):
- 冲 rush = small body + loud accent (yellow / magenta)
- 扛 tank = BIG dark metal (steel-blue / black + brass)
- 术 rule = violet body + ONE glowing gadget
- 援 support = teal-cyan glow on a skinny or pod shape
- Flying = wide horizontal + teal ring
- Size = HP: grey tiny, armor fills the panel. Never same height.
