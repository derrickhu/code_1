村民三阶立绘 · 出图规范 v2
========================

用途：图鉴 / 详情 / 村口排队。战场打击仍走 anim 切片。
本规范取代 evo_3stage_batch_prompt 和「紧裁 + 日常道具略放大」的旧法。
旧图两处硬伤：1) 横担 / 扳手伸出画布被切掉  2) 三阶还是过日子，看不出变强。

一、安全框（先于一切）
--------------------
- 单张立绘用 3:4 竖图。禁止 16:9 三连拍再切开（会把隔壁阶的锯子漏进来）。详见 evo_portrait_qc_v3_prompt.txt。
- 全身，3/4 正面，脚落地，三张同一视平线、同一镜头高度。
- 人物 + 全部道具必须完整落在框内。头上的阀、手里的柄、脚尖、背后的罐，一律不许贴边或被裁。
- 四边各留约 12% 空。脚离底、头离顶、左右最宽道具离边，都要看得见一圈底。
- 横道具宽度不得超过画布的 70%。扁担、渔网、音墙这类爱往两边伸的东西：
  往身体收、改斜扛、改背在身后往上长。禁止一根扁担横贯全画、两头出框。
- 去底之后按 alpha>=16 取包围盒（去底灰尘不要撑满画布），四周再留 24px，不要 4px 贴肉裁。
- NO TEXT, no labels, no numbers, no captions, no frames, no drop shadow on the ground.

二、同一个人
------------
- 三张同一张脸、同一身型、同一套描边。参考图只供脸和体型，不要抄参考图的构图和裁切。
- 乡下卡通：头大、身子敦、粗黑线、赛璐璐两级影、色只有土黄 / 水泥灰 / 塑料蓝 / 锈红。
- 不是精致漫画，不是写实老人。

三、进化必须改剪影，而且必须看着变强
--------------------------------
涂成纯黑剪影，陌生人要能立刻排出 1 < 2 < 3。
只换颜色、只换个杯盖、只把同一件东西略放大 —— 都不算。

一阶：过日子。家里那一件，轮廓最窄最矮。空手或一件贴身的家伙。
二阶： scrap 升级。轮廓明显变宽（肩甲 / 背后一件 / 手里换更大的家伙）。
三阶：能打外星人。必须同时满足：
  1. 头上有一件（盔 / 锅 / 阀）把头顶抬高
  2. 背后或肩上有一件把身子加宽加高
  3. 手里换了更凶的家伙（铁管、大锤、箱炮），不是还在做家务
  4. 衣服可以还是那件衬衫，但要有锈铁、铆钉、绳、蒸汽，看起来是武装，不是赶集

「挑水」「倒茶」「抱壶」可以是一阶的生活感，不能当三阶的最终形态。
三阶把同一件生活道具武器化：水桶变成加压罐，壶变成蒸汽炉，扁担变成短金属架贴在身上，不要一根长木棍横着挑。

四、后处理
----------
1. 生图（默认 Cursor GenerateImage；用户点名才用 Gemini）
2. 三阶对照条按 3×1 切开
3. rembg，卡通用 isnet-anime
4. crop_trim --padding 24
5. 拷进 assets/images/hero/{id}_evo{1,2,3}.png
6. 量一遍不透明包围盒，更新 portraitFit.ts，确认没有贴边裁切（四边透明 >= 16px）
