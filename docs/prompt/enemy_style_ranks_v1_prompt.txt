Monster rank sheets. The game is NOT an all-fodder roster.

HARD RULE: different RANKS must be different BODY TYPES, not the same grey in a new hat.
- 杂兵 = tiny naked grey person, ~35% of panel
- 冲 = still person-scale, loud color, lean
- 机关 / 飞 = the MACHINE is the body (tripod, dish-tower, saucer, incubator)
- 扛 = huge shell, 70%+ of panel
- 关底装甲 = mini-boss, fills the panel
