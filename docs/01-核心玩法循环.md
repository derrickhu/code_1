# 村口大战外星人 核心玩法循环

> **体验北极星**（更高优先级）：见 [00-体验目标.md](./00-体验目标.md)
> 主体验 = **我把一个杂兵改造成了怪物。**
> 本文所有循环与规则都是实现该体验的手段；新增或改动前先过体验目标的「设计审视清单」。

数值现状由 `npm run sim` 回归得出，断言钉在 `src/formulas/__tests__/simulate.test.ts`。

---

## 1. 核心循环

```
开局叫来 1 个村民 → 自动开打 → 波间三选一捡破烂 → 决定装给谁
      ↑                                                  ↓
  下一局换个人改  ←  卡在某一波  ←  按改装件调队列顺序
```

单局自闭环，局外只存最高波次，不做第二条养成线。

**「决定装给谁」是独立的一步，不自动分配。** 这一步就是这个游戏的核心动作；把它省成自动分配，游戏就退回「三选一加数值」。

## 2. 一列队列，不是棋盘

三个村民排成一队，队首先接敌，后面的靠射程支援。位置单位是「格」：队首站 0，往后依次 -1、-2；外星人从 6 格外走过来。

| 为什么这样 | 说明 |
|---|---|
| 站位要有表达空间 | Super Auto Pets 一排五格就让「谁站前面」成为整个构筑的核心 |
| 但不需要二维 | 二维棋盘是 TFT 那种体量才需要的。3×3 那一版换来的只有满屏小人、看不清敌人 |
| 上方六格全是空场 | 空场是舞台。外星人走进来才开打，那段路是给演出留的 |
| 上场只有 3 人 | 看戏要认得出脸。人一多，谁放了技能、怪从哪来，全糊在一起 |

**队首替后面的人挨刀**是队列唯一的规则，也是它全部的意义：外星人只打够得着的最靠前那个，队首倒下才轮到第二个。因此「谁站队首」是一个真决策，而改装件会不断改变这个决策的答案。

## 3. 失败条件：队灭或推不动

**没有底线血量，没有漏怪。** 这一条是三版战场都被认成塔防之后改掉的根因——换布局救不了，写着「漏怪扣血」就永远像塔防。

- 全队倒下 → 判负
- 一波打不完（超时 120 秒，即 DPS 不足推不动）→ 判负
- 打完 15 波 → 通关
- 每波开始全员复活满血，一次倒下不猝死。**每一波都是一出完整的戏**

外星人推到队尾后面也不产生任何惩罚，位置本身不判负。回归测试里专门钉了这一条。

## 4. 改装件：主体验的载体

三选一发的是破烂，玩家再决定装到谁身上。每件都必须能回答一句：**它让谁从什么变成了什么。** 只加百分比、不改打法的一律不做。

| 类别 | 件数 | 作用 |
|---|---|---|
| `pivot` 改定位 | 7 | 主体验的主力。射程、队首翻倍、越挨越猛、重击、溅射、穿透、站得起来 |
| `output` 纯强度 | 2 | 给已经成型的构筑补最后一脚 |
| `tanky` 更能挨 | 2 | 反弹与减伤，让队首撑得住 |
| `team` 帮全队 | 1 | 攻速光环 |

几个典型的定位改写：

| 破烂 | 效果 | 装上之后 |
|---|---|---|
| 接了根长水管 | 射程 +3 | 只能贴脸的近战，从此能站后面捅人 |
| 背了个高压锅 | 每挨一下攻击 +14%，本波叠 10 层 | 肉盾变主输出 |
| 绑了块钢板 | 站队首时伤害翻倍 | 远程被逼到最前面，而且值 |
| 秤砣绑手上 | 出手慢 80%，一下打 2.5 倍 | 快手改成重炮 |
| 摩托头盔 | 本波第一次倒下时半血站起 | 脆皮也敢站前面 |

两条硬约束：

- **一局内每件只出一次**（抽中即从池里拿掉）。12 件里发 7 件，组合每局不同，「这一局才有的戏」才立得住。
- **每人最多装 3 件**。有上限才有取舍，否则无脑堆一个人。

发牌规则：三张 kind 尽量互不相同，且**保证至少一张 pivot**。三张都是纯强度等于这一轮没有改定位的机会，主体验就断了一次。

## 5. 村民是起点，不是终点

六个村民，每人只有一个朴素的起手特性（护盾／治疗／溅射／连击／减速／吸血），用来给改造提供一个方向。**改定位的那几种效果一概不给村民自带**——否则「一个平平无奇的人被我改造成怪物」这句话的前半句就不成立了。回归测试钉了这一条。

**没有等级系统。** 局内唯一的成长来源是改装件，因此每件都是大事。加了等级就会出现「升级卡」这种只加数值的选项，直接撞反目标第一条。

选人只在开局与第 2、3 波各一次，共 3 人。之后全是改装件，一局 7 件。

## 6. 单局节奏

| 波次 | 内容 | 意图 |
|---|---|---|
| 1–3 | 小灰与方块兵，4 到 7 只 | 教学段，建立「他们自己能打」。第 1 波只 4 只，因为此时只有 1 个村民 |
| 4–6 | 加量，引入铁罐（护甲 32） | 第一次需要真输出，而不是站着挨 |
| 7 | 飞碟压阵 | 第一个可能卡住的点 |
| 8–12 | 数量与护甲混合 | **主卡关区**，也是复活广告的需求来源 |
| 13–15 | 高压收尾，终局刻意减量 | 终局要高潮不要数值墙 |

强度曲线是**分段**的：前 7 波 HP 按 1.15 复合，第 7 波之后降到 1.06，攻击从 1.10 降到 1.02。理由是卡关区被设计在 9 到 12 波，后段继续指数上升只会让已经打到那里的玩家撞上纯数值墙——而降得太狠又会出现「过了第 8 波就一路通关」的两极分布，这两个坑在调参时都踩过一次。

后段的压力主要来自**怪的数量与护甲**，不是血量指数。数量多会围攻队首，玩家的解法是范围伤害与硬队首，这正好把改装件推到台前。

当前回归结果（每策略 500 局）：

| 指标 | 实测（smart） | 目标 |
|---|---|---|
| 卡关中位数 | 12 波（p25 = 10，p75 = 15） | 9 到 12 波 |
| 第 10 波到达率 | 84% → 50%，坡度落在目标区 | 卡关区可感 |
| 单局时长 | 均 285 秒，通关局约 7 分钟 | 7 到 10 分钟 |
| 通关率 | 20.0% | 稀有但真实可达 |
| **装对人的价值** | 平均多打 3.03 波，通关率是乱装的 3.1 倍 | **≥ 1 波** |
| 构筑形状 | 全堆一个人 vs 平均分相差 1.38 波 | ≥ 0.8 波 |

「装对人的价值」是头号风险的唯一量化证据：`smart` 与 `random` 挑牌倾向完全相同，唯一差别是装给谁。**它掉到 1 波以下时不要调曲线，要回去加强 `mods.ts` 的定位改写强度。**

## 7. 观战可读性

主快感是看一队被自己改歪的人打赢。**看不懂就等于没做**，而自动战斗天然会让玩家怀疑自己的决策无效，所以表现层的首要任务不是好看，是让因果关系可读。

| 信息 | 表现 | 为什么排这个优先级 |
|---|---|---|
| **改造看得见** | 身上按件数挂小方块，名字后带 `+N`，底部改装条常驻列出每人装了什么 | 主体验第三个可检验点。玩家必须能指着屏幕说「他」 |
| 越挨越猛的层数 | 身侧小竖条随层数增加 | 高压锅是最标志性的定位改写，看不见就等于没装 |
| 谁在打谁 | 近战挥砍扇形、远程弹道、溅射走圆球弹 | 三个人同时开火时，没有指向就是一团乱闪 |
| 队首是谁 | 队首脚下常驻金圈 | 「谁替谁挨刀」是队列的全部意义 |
| 倒下与站起 | 倒下时全屏红闪一次；摩托头盔生效时金环外扩并飘「又站起来了」 | 警报挂在倒人身上，不挂底线——底线已经没有了 |
| 装配那一刻 | 装上时目标身上一圈金环，并飘出「××装上了××：变成了××」 | 这一步是核心动作，必须有回执 |
| 波次预告 | 说清这一波难在哪（硬、多、快） | 让「换个人装」成为比「重开碰运气」更清晰的路径 |

反过来，明确不做：遮挡战场的全屏演出、超过 0.3 秒的技能停顿、同屏超过两种屏幕震动、在上方空场里铺格子或画防线。

## 8. 十秒开场

「十秒可懂」是硬约束，直玩已是 IAA 买量第一大形态。开局不允许有编队页等任何前置流程。

| 时间 | 画面 |
|---|---|
| 0.0s | 直接在战场上，三张村民卡升起，中央提示「叫谁来」 |
| 1.5s | 玩家点卡；若 3 秒未点则高亮其中一张引导点击 |
| 2.0s | 村民落地，冲击波扩散，名字与起手特性浮现 |
| 3.0s | 第一波小灰从上方空场走进来 |
| 4.0s | 村民自动动手，首次命中的伤害飘字刻意放大 |
| 6.0s | 第一个小灰倒下 |
| 8.0s | 底部提示「外星人下来了，撑过 15 波」 |

第 4 波起玩家第一次拿到破烂并选择装给谁——那是「十秒可懂」之后紧接的第二个钩子。

验收方式是录前 10 秒给没玩过的人看，问他这游戏在干什么。说不出「捡破烂装身上、他们自己打」就要改开局；若他说「这是塔防」，回去查第 3 节。

## 9. 广告位

核心流程只放 2 个。依据是大盘数据：核心单流程广告点少于 3 个时新进次留约 23%，3 到 5 个掉到 17%，而 xiaochu2 排了 4 个正落在差的那档。

| 广告位 | 位置 | 日限 | 核心流程 |
|---|---|---|---|
| 结算奖励双倍 | 局末结算页，默认焦点并显示双倍后的具体数值 | 5 | 是 |
| 队灭原地站起 | 全队倒下的当下，就地救活全队并继续当前波 | 2 | 是 |
| 每日首局多带一件 | 进入首局前，开局白送一件改装件 | 1 | 否，局外 |
| 每日免费翻废品站 | 主界面入口，看一件本局池外的破烂 | 1 | 否，局外 |

复活的卖点是「保住这套已经改成型的组合」，不是「重开一局」——这也是为什么失败判定是队灭：玩家在看着三个人一个个倒下的过程里自己意识到危险，广告卖在那之后，而不是猝死瞬间。**不接插屏**：平台把插屏与激励视频算在同一频控窗口，而激励视频 eCPM 明显更高。

## 10. 埋点事件表

必须在跑数值之前接好，否则验收阶段没有数据可看。

| 事件 | 关键字段 | 用途 |
|---|---|---|
| `run_start` | seed, opening_hero | 局数统计、开局村民分布 |
| `run_end` | reached_wave, cleared, duration_ms, team_with_mods, installs | **卡关波次分布**，核心验收指标 |
| `wave_clear` | wave, duration_ms, alive_count | 定位哪一波过陡 |
| `pick_show` | wave, options, kinds | 与 choose 配对算选择率 |
| `pick_choose` | wave, mod_id, kind, options | **验证取舍**：某一 kind 被选超过 60% 即说明没有真取舍 |
| `mod_install` | wave, mod_id, target_hero, target_slot, target_mod_count | **验证主体验**：同一件破烂是否被装给不同的人 |
| `queue_change` | wave, order_before, order_after | 改装件是否真的带来了站位决策 |
| `hero_down` | wave, hero_id, slot | 队首是否总是同一个人倒 |
| `ad_show` / `ad_close` | placement, wave, completed | 中位数 IPU、各位点利用率 |

四个必看指标：

1. **中位数 IPU ≥ 6** —— 看中位数不看平均。xiaochu2 的教训是两名重度用户能把均值抬到 7.9，而一个活跃玩家真实值只有 0.57。同时看「开战 ≥20 场的人里 IPU < 2 的占比」。
2. **`mod_install` 的目标分布** —— 某个位置被装超过 70%，说明改装件与村民的搭配没有真差异，回去改 `mods.ts` 而不是改数值。
3. **`queue_change` 发生率** —— 如果绝大多数玩家从不调队列，说明「装了什么决定他该站哪儿」这条连带决策没有被感知到。这一条比卡关分布更早预警。
4. **`pick_choose` 的 kind 分布** —— 某一 kind 超过 60% 就回来改发牌规则。
