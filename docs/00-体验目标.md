# 村口大战外星人 · 体验目标（设计北极星）

> **本文件优先于一切玩法、数值、系统、商业化文档。**  
> 后续任何设计、改需求、加系统，都必须先用本文「审视清单」过一遍；通不过则改方案或砍掉，而不是改体验目标去迁就功能。

品类：单局肉鸽制的角色改造自走战斗  
平台：微信 / 抖音小游戏　变现：首版纯 IAA；IAP 只预留结构，待版号后再开（见 §5.1）

---

## 1. 基调

**一句话世界观**

> 外星人降落在县城，村口这帮闲人翻出五金店和废品站的破烂，把自己改成了猛货。

土味打高科技。这个基调不是包装，是玩法的一部分：改装件必须是**一眼就知道能干什么的实物**——电锯、鼓风机、高压锅、灭火器、弹簧床垫。玩家不需要读技能描述就懂，这是「十秒可懂」的实现手段，也是笑点的来源。

| 项 | 定 |
|---|---|
| 角色 | 村口闲人。二舅、铁柱、三婶、老烟枪一类，一听就是身边人 |
| 敌人 | 外星人。画得高级又呆，才衬得出被一群大爷用锅盖打退的荒诞 |
| 画风 | 大脑袋、粗描边、6–8 色、两档色块阴影（沿用既有风格板，不换画风） |
| 色系 | 村口用暖土黄／水泥灰／塑料蓝／生锈红；外星人用冷紫青，两边拉开 |
| 文案 | 短句、口语。胜利说「整挺好」，不说「战斗胜利」；技能叫「绑了个鼓风机」，不叫「焦甲」 |
| 音效 | 实物声：电锯、鼓风机、锅盖、鞭炮、广场舞音响。外星人用干净电子音形成对撞 |

**命名规则**：夸张归画面，文字只负责好笑和说清楚。不要奇幻词（熔岩卫、春息祭司），不要史诗腔。

## 2. 主体验目标

**正式表述**

> 当玩家在碎片时间开一局时，反复感到：**「这个平平无奇的人，被我改造成了本局的怪物」**——赢来自我把哪件破烂装到了谁身上，而不是我手速快或者肝得久。

**一句话**

> **我把一个杂兵改造成了怪物。**

**玩家应脱口而出**

- 「这套组合也太离谱了」
- 「刚才那件装他身上真是神了」
- 「他现在得站最前面才吃得到伤害加成」

**这句话的含义要落到三个可检验的点**

1. **本局独有**：这一局叠出来的组合，和上一局不一样。变化不是数值累加，是定位被改写。
2. **改造对象是具体的人**：破烂装在某一个村民身上，不是全队 buff。玩家能指着屏幕说「他」。
3. **改造看得见**：变强这件事在画面上直接成立——身上多了东西，攻击方式变了。不靠数字飘字说明。

## 3. 反目标（坚决避免）

玩家若经常感到以下任一，即体验目标失败：

| 反目标感受 | 典型诱因（设计上要挡） |
|---|---|
| **「这几件破烂装谁身上都一样」** | 改装件只加数值不改定位；没有「装错人」的可能 |
| 「满屏都是人，看不清谁在打谁」 | 上场人数过多；战场被单位填满，没有留给演出的空场 |
| 「打不过就是运气不好」 | 随机性主导结果；出现无法应对的对位惩罚 |
| 「每回合还要手动点，累」 | 把自动战斗改回手操；观战被操作打断 |
| 「这不就是个塔防吗」 | 失败条件回到「守住别漏」；出现路径、阻挡数、防线血条 |
| 「系统太多，不知道该干啥」 | 多养成线、多货币、局外目标冲突 |

**头号风险是第一条。** 自动战斗天生会让玩家怀疑自己的决策无效，所以每一件改装件都必须能回答一句：它让谁从什么变成了什么。只加 12% 攻击的改装件不做。

**第五条是这个项目栽过的坑。** 长路站桩、短距对撞、3×3 棋盘三版战场都被试玩者第一眼认成塔防，根因始终是失败条件写着「漏怪扣底线血」。换布局救不了幻想，所以失败条件本身已改（见 §4）。

## 4. 玩法骨架（体验的实现方式）

| 层级 | 内容 | 说明 |
|---|---|---|
| **主** | 三选一拿改装件 → 决定装给谁 | 「装给谁」这一步就是主体验的动作，不能省成自动分配 |
| **强辅** | 自动战斗的观战爽感 | 让「装对了」的结果打得好看、看得懂；不抢主目标 |
| **弱辅** | 村民阵容（开局与前两次选人） | 给改造提供不同的起点；不做成第二条收集线 |

**硬性骨架**

| 项 | 值 | 为什么 |
|---|---|---|
| **失败条件** | 全队倒下，或一波推不动（超时） | 只要还写「漏怪扣血」，第一眼永远是塔防 |
| **胜利条件** | 打完 15 波 | |
| **上场人数** | 3 人 | 看戏要认得出脸。人一多，谁放了技能、怪从哪来，全糊在一起 |
| **站位** | 一列有序队列，前面的人先接敌 | 站位是构筑的一部分（Super Auto Pets 一排五格即可，不需要棋盘） |
| **战场** | 队列之间留出空场，敌人走进来才开打 | 空场是舞台。屏幕不是用来填满单位的 |
| **每人改装上限** | 3 件 | 有上限才有取舍，否则无脑堆一个人 |
| **克制系** | **不做** | 3 人固定队没有换人对位的空间，克制会退化成无法应对的运气惩罚，直接撞反目标第三条 |

**聪明感的关键时刻**：某件破烂装上去，一个原本不起眼的村民突然成了本局核心，于是玩家主动把他挪到队列前面（或后面）去配合。  
若玩家卡关后第一反应是「再来一局碰运气」而不是「这次换个人装」，主目标已偏。

## 5. 游玩情境（设计约束）

以下每条都是硬约束，不是建议。来源是市场与买量调研，以及 xiaochu2 的实测教训。

| 约束 | 值 | 为什么 |
|---|---|---|
| 单局长度 | 15 波，7–10 分钟 | 碎片时间可完整打完一局；短回收模型要求成长压进单局 |
| **十秒可懂** | 前 10 秒内玩家能看懂「捡破烂装身上 → 他们自己打」 | 直玩已是 IAA 买量第一大形态（头部渗透率 95%、点击转化率提升 3 倍）。开局不允许有编队页等前置流程，必须直接进战场 |
| **核心流程广告点 ≤ 2** | 只放「结算双倍」与「队灭复活」 | 大盘数据：核心单流程广告点少于 3 个时新进次留约 23%，3–5 个掉到 17%。xiaochu2 排了 4 个，正落在差的那一档 |
| **中位数 IPU ≥ 6** | 人均日广告展示次数，看中位数不看平均 | 纯 IAA 的收入底线。xiaochu2 平均 7.9 看似达标，实际是两名重度用户抬起来的，一个活跃玩家真实值只有 0.57 |
| 不接插屏 | 切片与首版都不接 | 平台把插屏与激励视频算在同一频控窗口，而激励视频 eCPM 明显更高，接插屏等于用贵的换便宜的 |
| 首版无内购 | 不开 IAP，但按 §5.1 预留结构 | 没有版号，且小游戏开内购另需资质与审核。任何「靠付费深度才能过」的设计在无版号期都无法变现，只会变成劝退 |

### 5.1 IAP 预留原则

首版纯 IAA，但**结构从第一天就要留**。理由来自 xiaochu2 的实测教训：如果免费经济先按「完全没有付费」校准过一轮，等到能开付费时再塞进去，只能靠打折扣硬挤，最后变成付费不值钱、免费也被削。

预留的成本几乎全在**口径**上，不在功能上。按下面三档执行。

| 档位 | 内容 | 为什么归在这一档 |
|---|---|---|
| **现在就必须定** | ① 所有资源发放走同一入口，带 `source` 字段（`free` / `ad` / `iap` / `quest`）<br>② 资源账本以服务端为权威，订单幂等接口形状先留好<br>③ 定义「一次广告 = 多少资源」这把尺子，让日后定价能挂到同一把尺上<br>④ 埋点按 `source` 分账，收入能拆出 IAA 与 IAP | 这几项事后改等于重做存档信任模型与全部数值校准，是唯一真正贵的部分。**注意只做接口形状，不接支付 SDK** |
| **可以后加** | 商店 UI、SKU 清单、定价、首充与月卡、支付 SDK 接入、审核资质 | 都是叶子功能，加的时候不动核心循环。版号周期本身是半年到一年以上，现在做实现纯属浪费 |
| **即便开了 IAP 也不做** | 卖改装件或改装件抽卡；直售战力数值；付费墙式难度曲线 | 前两条撞主体验目标——改造的快感来自「我把它装对了」，一旦改装件能买，构筑就变成付费进度条。第三条撞《保卫向日葵》的教训：它靠局外装备与钻石强娶变现，代价是零氪打几章就卡关 |

**日后 IAP 优先卖外观。** 改装件天生是视觉物件，外观是它的自然延伸，既不破坏平衡、不制造付费墙，也不与 IAA 的广告位争夺同一份玩家意愿。去广告类商品要谨慎评估：它直接吃掉 IAA 收入，只有在月卡 LTV 明确高于该玩家的广告价值时才成立。

## 6. 设计审视清单（必过）

新增或改动玩法 / 数值 / UI / 商业化前，逐条回答。任一条为「否」且无法修正 → **不做或降权**。

1. **改造能改定位**：这件改装件是否让某个角色从一种打法变成另一种？（纯数值加成不算）
2. **装给谁有差异**：同一件改装件装在不同人身上，结果是否明显不同？
3. **看得清**：场上是否仍认得出谁是谁、谁在打谁？新增演出是否遮挡了战场？
4. **不像塔防**：是否引入了防线血条、漏怪惩罚、路径或阻挡数？若是，直接砍。
5. **卡关路径**：玩家卡住时，游戏是否把「换个人装 / 调队列顺序」提示为比「再来一局碰运气」更清晰的路径？
6. **胜利归因**：结算是否让人感到「我改对了」，而不是只感到「这局运气好」？
7. **十秒可懂**：改动后，前 10 秒是否仍能让没玩过的人看懂在干什么？
8. **广告点预算**：核心流程广告点是否仍 ≤ 2？新增曝光是否放在了局外？
9. **变现不成为前置**：变现是否制造「不看广告就过不去」或「不付费就过不去」？若是，违反反目标。涉及 IAP 商品时追加一问：这件商品若上线，是否会让不付费玩家的现有体验变差？会则不做。
10. **系统负担**：是否增加了让玩家忘记「改造」的干扰目标？（多养成、多货币、复杂任务）

## 7. 加 / 慎 / 砍（速查）

| 倾向 | 例子 |
|---|---|
| **加** | 能改写定位的改装件、装上后画面立刻不同、队列顺序的即时反馈、结算里点明「本局靠谁打过的」、波次预告说清下一波难在哪 |
| **慎加** | 局外成长线、纯数值改装件、遮挡战场的演出、第四个村民（先验 3 人是否够看） |
| **砍 / 降权** | 防线血条与漏怪惩罚；克制系；二维棋盘；阻挡数与路径规划；改装件抽卡与付费战力养成（即便日后开 IAP 也不做，见 §5.1）；前置编队流程；核心流程的第三个广告点；插屏 |

## 8. 验收标准（体验是否达标）

| 维度 | 标准 | 测法 |
|---|---|---|
| **体验** | 玩家能说出本局是靠「谁 + 哪件破烂」打到那一波的 | 试玩后问「刚才是什么让你打到第 12 波」。答案指向某个角色和某件改装件即通过；答「运气」或「不知道」即不通过 |
| **辨识** | 玩家能说出场上三个人分别在干什么 | 看 30 秒后问。说不清即上场人数或演出有问题 |
| **不像塔防** | 没玩过的人看完前 10 秒，不会说这是塔防 | 录前 10 秒盲测 |
| **商业** | 中位数 IPU ≥ 6，且次留不低于改动前 | 埋点看中位数，同时看「开战 ≥20 场的人里 IPU < 2 的占比」 |
| **节奏** | 卡关点稳定落在第 9–12 波 | 数值原型阶段就要验；太早挫败，太晚则复活广告没需求 |

三条里最可能挂掉的是**体验**那条。它挂了就不是调参能救的，要回到改装件的定位改写强度。

## 9. 与其他文档的关系

本文件是唯一的体验裁决依据。后续新增的核心玩法循环、数值框架、商业化配置等文档，都是实现本文的手段，不具备更高优先级。数值调参的验收是「换个人装能打得更深，重开碰运气不是最优解」，而不是只看曲线平滑。
