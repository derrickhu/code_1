# 村口大战外星人 · 体验目标（设计北极星）

> **本文件优先于一切玩法、数值、系统、商业化文档。**  
> 后续任何设计、改需求、加系统，都必须先用本文「审视清单」过一遍；通不过则改方案或砍掉，而不是改体验目标去迁就功能。

品类：村民收集进化 + 分路布阵的自动塔防  
平台：微信 / 抖音小游戏　变现：首版纯 IAA；IAP 只预留结构，待版号后再开（见 §5.1）

---

## 1. 基调（本版升级为硬约束）

**一句话世界观**

> 外星人降落在县城。村口这帮闲人不肯搬，翻出五金店和废品堆的破烂往身上焊，一个个焊成了猛货；人手不够就去村委会大喇叭喊一嗓子，再叫一个来。

土味打高科技。这句话的两半分别对应主体验的两半：**往身上焊**是进化，**喊一嗓子**是收集。

**这一节在本版从「风格指南」升级成「硬约束」，因为它现在是唯一的护城河。** 玩法骨架换成了分路布阵的自动塔防——一个大家都认得的品类；同时我们主动下线了唯一的自研机制（改装件构筑，见修订记录 2026-09-04）。差异化因此**全部**押在这一节和 §4.1 的进化形态上。这不是「也要注意基调」，这是「基调没做到，产品就没有存在理由」。

落到三条不许违反的：

1. **场上站的必须是有名有姓、认得出脸的村口闲人**，不是数值不同的通用炮塔。玩家要能说「我那个铁柱」。
2. **变强必须靠身上多焊出来的实物来表达**——电锯、鼓风机、高压锅、灭火器、弹簧床垫。不靠发光词条、不靠数字飘字。
3. **文案与音效不许走向通用奇幻**。胜利说「整挺好」，敌人被锅盖打退。


| 项   | 定                                          |
| --- | ------------------------------------------ |
| 角色  | 村口闲人。二舅、铁柱、三婶、弹弓叔一类，一听就是身边人                |
| 敌人  | 外星人。画得高级又呆，才衬得出被一群大爷用锅盖打退的荒诞               |
| 画风  | 大脑袋、粗描边、6–8 色、两档色块阴影（沿用既有风格板，不换画风）         |
| 色系  | 村口用暖土黄／水泥灰／塑料蓝／生锈红；外星人用冷紫青，两边拉开            |
| 文案  | 短句、口语。胜利说「整挺好」，不说「战斗胜利」；形态叫「焊了个鼓风机」，不叫「焦甲」 |
| 音效  | 实物声：电锯、鼓风机、锅盖、鞭炮、广场舞音响。外星人用干净电子音形成对撞       |


**命名规则**：夸张归画面，文字只负责好笑和说清楚。不要奇幻词（熔岩卫、春息祭司），不要史诗腔。

## 2. 主体验目标

**正式表述**

> 当玩家在碎片时间打几关时，反复感到：**「这一村子人是我一个个攒出来、喂大的，这条线是我排出来的」**——赢来自我攒了谁、把谁喂到了几阶、又把谁放在了哪一路，而不是我手速快或者肝得久。

**一句话**

> **我攒出了一村子的怪物，排出一条挡得住的线。**

**玩家应脱口而出**

- 「二舅喂到三阶完全变了个人」
- 「这一路得放个挨得住的，不然中路先崩」
- 「这关来的是下手重的，把越挨越猛那几个换上去」
- 「就差两个工分，喇叭一喊把三婶叫来」

**这句话的含义要落到三个可检验的点**

1. **攒得出人**：每个村民有名有姓、认得出脸、别人替不了他的活。收集的乐趣来自「他是谁」，不来自「他数值高」。
2. **喂得看得见**：进化改的是这个人的打法和形态——身上多焊了东西、攻击方式变了。不是把数字调大。
3. **布阵有对错**：同一批人，排法不同结果明显不同。玩家能指着某一路说「这儿放错了」。

**和上一版的关系。** 上一版主体验是「我把一个杂兵改造成了怪物」，动作是局内三选一把破烂装给谁。本版把「改造」从**每局的随机构筑**整个移到了**永久的收集与进化**上：不再有三选一，破烂不再是可选的牌，而是进化形态的样子。主决策从「装给谁」换成了「攒谁、喂谁、放哪一路」。

## 3. 反目标（坚决避免）

玩家若经常感到以下任一，即体验目标失败：


| 反目标感受              | 典型诱因（设计上要挡）                          |
| ------------------ | ------------------------------------ |
| **「这就是个换皮塔防」**     | 单位退化成通用炮塔；村民没名没姓；变强看不出来；土味丢了         |
| **「攒来攒去都长一样」**     | 村民辨识度不足；进化只改数值不改形态；定位互相重复；池子靠调参堆数量   |
| **「打不过就是被克了，没办法」** | 敌方门路开战前看不到；村民池不够换人；克制倍率过高；喂大主力的路被堵死  |
| 「格子里全是人，看不出哪一路要崩」  | 单位体型一致、格子之间没有视觉分隔、同屏特效过多             |
| 「每回合还要手动点，累」       | 把自动战斗改回手操；观战被操作打断                    |
| 「系统太多，不知道该干啥」      | 资源超过 4 种、多入口、局外目标互相冲突；点开村子说不出下一步该干什么 |


**头号风险是第一条和第二条，而且这两条是本版自己买来的。**

- **第一条**：玩法结构已经是公认品类，自研机制又主动下线了，于是「我们凭什么不是换皮」这个问题第一次没有玩法层的答案。唯一的答案在 §1 和 §4.1。挡它的手段只有一个：场上每个单位都必须是认得出脸的村民 + 看得出来的实物改造。
- **第二条**：这是收集品类的固有病。村民池要从 6 扩到 20+，一旦是靠「换个数值、换个颜色」堆出来的，收集就变成了刷进度。每一个新村民都必须能回答一句：**别人替不了他什么活**。

**上一版的头号风险（「这几件破烂装谁身上都一样」）已随改装件系统一起下线。** 它保护的是局内构筑，本版没有局内构筑了。

**上一版的反目标第五条「这不就是个塔防吗」已删除。** 那条曾是本项目栽过三次的坑（长路站桩、短距对撞、3×3 棋盘三版战场都被第一眼认成塔防），当时的解法是把失败条件从「漏怪扣血」改掉。本版做的是相反的决定：**承认并接受塔防定位**，把差异化从玩法结构挪到基调与收集深度上。这是有意的方向反转，不是遗漏——代价见修订记录 2026-09-04。

## 4. 玩法骨架（体验的实现方式）


| 层级     | 内容                            | 说明                                  |
| ------ | ----------------------------- | ----------------------------------- |
| **主**  | 开战前布阵：谁上场、站哪一路哪一格、按敌方门路换人     | 「排这条线」是每一关都要做的决策动作，不能省成自动布阵或推荐阵容一键上 |
| **强辅** | 收集与进化：喊人入伙、喂到几阶               | 「攒」的那一半。长线的主要去处，也是主体验里「怪物」二字的来源     |
| **强辅** | 弹弓摊：一发两秒，掉村庄经验 / 废铁 / 零件 / 工分 | 局外的高频动作与回访理由。它是资源唯一出口，不是第二个玩法       |
| **弱辅** | 自动战斗的观战爽感                     | 让「攒对了、排对了」的结果打得好看、看得懂；不抢主目标         |


### 4.1 进化改的是打法和形态，不是数值

**这是本版唯一承载产品身份的机制，优先级等同于 §1。**

每个村民三阶。**每进一阶，他身上多焊一层看得出来的破烂，攻击方式跟着变。** 例如铁柱：一阶是三层棉袄加摩托头盔，二阶焊上钢板，三阶顶着高压锅、背着弹簧床垫。

三条硬要求：

1. **每一阶必须有独立立绘**，不许只换颜色或加光效。看不出变化的进化等于没做。
2. **每一阶必须改攻击方式或射程**，不许只调数值。三阶的铁柱不能只是「血更多的一阶铁柱」。
3. **形态用的是实物，不是特效**。这是 §1 第 2 条在机制层的落地。

**改装件系统（`mods.ts` / `lanes.ts` / `combos.ts` / `picker.ts`）作为机制已整体下线，但作为视觉语言全部保留。** 那 27 件破烂的美术资源变成进化立绘的构件——它们从「玩家每局要选的牌」变成「玩家看得见的成长痕迹」。这是本版在砍掉一整套系统之后，唯一没有丢掉的东西。

### 4.2 门路：天生的定位，也是克制属性

村民的门路**天生固定**，不可更改：站远点打 / 挨得住 / 下手重 / 越挨越猛 / 带一帮人。

它同时是定位（决定他该站哪一格）和克制属性。**循环**：站远点打 → 带一帮人 → 挨得住 → 下手重 → 越挨越猛 → 站远点打（前者克后者）。

2026-08-18 曾明确裁掉克制系，理由是 3 人固定队没有换人对位的空间，克制会退化成运气惩罚。本版敢做，是因为三件事同时成立：**上场人数抬到 8、村民池扩到 20+、敌方门路开战前可见**。这三件缺任何一件，克制就立刻退回运气惩罚，必须整条撤掉而不是调倍率（见 §6 第 4 条）。

### 4.3 喊人入伙：村民是人，不是宠物

收集的动作是**去村委会大喇叭喊一嗓子，把人叫来入伙**，不是抓、不是开箱、不是从笼子里放出来。

这条写进硬约束，因为它是 §1 第 1 条（场上必须是有名有姓的村口闲人）在收集层的延伸。对标产品收集的是宠物，抓和关笼子都成立；我们收集的是**人**，同一套包装照搬过来会当场破掉基调——一个村里人被关在铁笼里等你撬开，这不是土味，这是走味。

落地口径：

- **工分**是喊人的门槛。弹弓摊靶面上最偏的那个是挂着的旧喇叭，打中响一声、记一个工分；攒够一批去大喇叭喊人。
- **喊到已经入伙的人**，就当他捎了东西来：折成废铁，并给他加一颗星。不出现「重复角色碎片」这类说法。
- **不做稀有度弹窗**（金光、SSR、彩虹）。喊来的是二舅，不是一张卡。

### 4.4 硬性骨架


| 项           | 值                         | 为什么                                                                  |
| ----------- | ------------------------- | -------------------------------------------------------------------- |
| **失败条件**    | 漏怪到底线，或限定时间内没打完           | 本版承认塔防定位（见 §3 末）。商业约束随之改口径：复活广告卖的是「漏了那一下重来」，所以**漏怪必须是失败局的多数**，超时只当兜底 |
| **胜利条件**    | 波次出完且没漏，按清关效率与残存状态给 1–3 星 | 星评是重打一关的理由，也是「我排得更好了」的量化反馈                                           |
| **战场**      | 3 路 × 4 格。上方留出空场，敌人走进来才开打 | 空场是舞台。分路是为了让「哪一路要崩」看得出来，不是为了增加格子数                                    |
| **上场人数**    | **8 人**（村庄等级从 3 逐步抬到 8）   | 12 个格子只能放 8 个人，**必须选哪一路厚哪一路薄**——空着的 4 格就是取舍。上场人数是村庄等级最直观的奔头          |
| **村民池**     | 20+，每人 3 阶形态              | 收集是本版的主要长线，池子小于 20 则克制没有换人空间（见 §4.2）                                 |
| **布阵时机**    | 开战前拖人上格；开打后不可更改           | 决策必须在开打前完成，否则退化成手操（撞反目标第五条）。想给容错就放在星评上，不放在战中改阵                       |
| **克制倍率**    | ×1.3 / ×0.77，且敌方门路开战前必须可见 | 刻意压低。克制要能让人想换阵，但不许让被克的阵容打不过去（见 §8「克制不是惩罚」）                           |
| **单关长度**    | 3–5 波，1–2 分钟              | 从 15 波 7–10 分钟改过来。碎片时间打几关比打完一局更适合小游戏，也让结算广告位的机会变多                    |
| **局内成长**    | **不做**                    | 本版没有三选一、没有局内升级、没有局内拿装备。变强全部发生在局外，局内只验证「攒得对不对、排得对不对」                  |
| **放出来的小东西** | 不算上场人数，全队同屏 ≤ 4 只         | 狗、鸡、乡亲**不占格子**、不能点、画得比村民矮一截。它们让场面像两军对撞，但「认得出脸」那条不破                   |
| **主动技能按钮**  | **不做**                    | 按钮谁按都一样，会把归因从「攒谁、放哪路」上抢走                                             |
| **推荐阵容一键上** | **不做**                    | 它会把主体验的决策整个替掉。可以给敌方门路提示，不给答案                                         |


**聪明感的关键时刻**：某一关连输两次，玩家把攒了几天的二舅喂到三阶、挪到最先接敌的那一格，同时把被克的那两个换下来，这一关就过了。  
若玩家卡关后第一反应是「回去硬刷村庄等级」而不是「换人 / 换站位 / 喂大主力」，主目标已偏。

## 5. 游玩情境（设计约束）

以下每条都是硬约束，不是建议。来源是市场与买量调研，以及 xiaochu2 的实测教训。


| 约束              | 值                                               | 为什么                                                                                                                 |
| --------------- | ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 单关长度            | 3–5 波，1–2 分钟                                    | 碎片时间可完整打完几关；短关让星评重打和结算广告都有机会                                                                                        |
| **十秒可懂**        | 前 10 秒内玩家能看懂「一群大爷分三路挡外星人」                       | 直玩已是 IAA 买量第一大形态（头部渗透率 95%、点击转化率提升 3 倍）。**第一关必须预置阵型直接开打**，布阵页从第 2 关才出现——这是上一版「开局不允许有编队页」那条硬约束在本版的落地方式，约束没有放松，只是换了实现 |
| **核心流程广告点 ≤ 2** | 只放「星评结算双倍」与「漏了那一下重来」                            | 大盘数据：核心单流程广告点少于 3 个时新进次留约 23%，3–5 个掉到 17%。xiaochu2 排了 4 个，正落在差的那一档。弹弓摊的广告位算局外，不占这两个                                 |
| **中位数 IPU ≥ 6** | 人均日广告展示次数，看中位数不看平均                              | 纯 IAA 的收入底线。xiaochu2 平均 7.9 看似达标，实际是两名重度用户抬起来的，一个活跃玩家真实值只有 0.57                                                     |
| 不接插屏            | 切片与首版都不接                                        | 平台把插屏与激励视频算在同一频控窗口，而激励视频 eCPM 明显更高，接插屏等于用贵的换便宜的                                                                     |
| 首版无内购           | 不开 IAP，但按 §5.1 预留结构                             | 没有版号，且小游戏开内购另需资质与审核。任何「靠付费深度才能过」的设计在无版号期都无法变现，只会变成劝退                                                                |
| **资源种类 ≤ 4**    | 废铁（喂进化）、零件（卡进阶门槛）、工分（喊人入伙）、村庄经验（公共等级）。弹子是次数不是货币 | 本版是新增资源最多的一次，反目标第六条的风险随之最高。弹子不进货币条、不能买、没有第二个去处；一旦玩家问出「弹子能买什么」就说明它变成了第五种货币，届时砍掉存量改成纯次数                               |


### 5.1 IAP 预留原则

首版纯 IAA，但**结构从第一天就要留**。理由来自 xiaochu2 的实测教训：如果免费经济先按「完全没有付费」校准过一轮，等到能开付费时再塞进去，只能靠打折扣硬挤，最后变成付费不值钱、免费也被削。

预留的成本几乎全在**口径**上，不在功能上。按下面三档执行。


| 档位               | 内容                                                                                                                                                           | 为什么归在这一档                                                                                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **现在就必须定**       | ① 所有资源发放走同一入口，带 `source` 字段（`free` / `ad` / `iap` / `quest`） ② 资源账本以服务端为权威，订单幂等接口形状先留好 ③ 定义「一次广告 = 多少资源」这把尺子，让日后定价能挂到同一把尺上 ④ 埋点按 `source` 分账，收入能拆出 IAA 与 IAP | 这几项事后改等于重做存档信任模型与全部数值校准，是唯一真正贵的部分。**注意只做接口形状，不接支付 SDK**                                                                                                              |
| **可以后加**         | 商店 UI、SKU 清单、定价、首充与月卡、支付 SDK 接入、审核资质                                                                                                                         | 都是叶子功能，加的时候不动核心循环。版号周期本身是半年到一年以上，现在做实现纯属浪费                                                                                                                           |
| **即便开了 IAP 也不做** | **喊人付费抽卡与保底加速**；直售战力数值；付费墙式难度曲线                                                                                                                              | 第一条是本版新增的最大诱惑，也是最危险的一条：村民池扩到 20+ 之后喊人这套天生长得像卡池，而收集已经是主体验，一旦能付费抽，「攒出一村子怪物」就直接变成付费进度条，撞主体验目标。它同时会拖垮 §4.3——一旦要卖，就会有人想加稀有度弹窗和金光。第三条撞《保卫向日葵》的教训：它靠局外装备与钻石强娶变现，代价是零氪打几章就卡关 |


**日后 IAP 优先卖外观。** 村民与进化形态都是视觉物件，外观是它的自然延伸，既不破坏平衡、不制造付费墙，也不与 IAA 的广告位争夺同一份玩家意愿。去广告类商品要谨慎评估：它直接吃掉 IAA 收入，只有在月卡 LTV 明确高于该玩家的广告价值时才成立。

## 6. 设计审视清单（必过）

新增或改动玩法 / 数值 / UI / 商业化前，逐条回答。任一条为「否」且无法修正 → **不做或降权**。

1. **认得出是谁**：场上这个单位，玩家认得出他是谁、说得出他别人替不了的活吗？若它已经退化成一个数值不同的塔，直接砍。
2. **进化改打法**：这一阶进化是否改了攻击方式或射程，并且有独立立绘？只调数值的进化不做。
3. **新村民有存在理由**：这个新人是否补了一个现有池子补不上的活？只是数值更高、颜色不同的，不做。
4. **克制不是惩罚**：敌方门路是否开战前就看得见？被克的阵容是否仍有打过去的办法（换人 / 换站位 / 喂大主力）？三者缺一，克制整条撤掉而不是调倍率。
5. **看得清**：场上是否仍认得出谁是谁、哪一路要崩？新增演出是否遮挡了战场？
6. **卡关路径**：玩家卡住时，游戏是否把「换人 / 换站位 / 喂大主力」提示为比「回去硬刷村庄等级」更清晰的路径？
7. **胜利归因**：结算是否让人感到「我攒对了、排对了」，而不是只感到「等级够了」？
8. **十秒可懂**：改动后，前 10 秒是否仍能让没玩过的人看懂在干什么？布阵是否仍然不出现在第一关？
9. **广告点预算**：核心流程广告点是否仍 ≤ 2？新增曝光是否放在了局外？
10. **变现不成为前置**：变现是否制造「不看广告就过不去」或「不付费就过不去」？若是，违反反目标。涉及 IAP 商品时追加一问：这件商品若上线，是否会让不付费玩家的现有体验变差？会则不做。
11. **系统负担**：资源是否仍 ≤ 4 种？是否增加了让玩家忘记「攒人和排阵」的干扰目标？局外线的条数不是罪，**说不出下一步该干什么才是**。
12. **养成不许买掉布阵决策**：这条局外线买满之后，「谁放哪一路」还值不值钱？回归里 smart 布阵与 random 布阵的差值必须仍显著（见 §8）。买完就不用排阵了，这条线重做而不是调数。
13. **花钱不许更难**：这一笔买下去，通关率是往上走的吗？上一版真踩过（教训保留，涉及的门路研发系统本版已下线）：那一版只改发牌份量不改数值，结果专精一路等于把别路的强件从池子里挤走，满研发后通关率从 15% 掉到 7%——玩家花了 595 买到的是更难打。这类「负回报」比数值过强危险得多。
14. **上场人数不许换来看不清**：每抬一档上场人数，都要重问一遍第 5 条。抬到 8 是上限，不许再往上加。

## 8. 验收标准（体验是否达标）


| 维度           | 标准                                  | 测法                                                                                                                                                                                        |
| ------------ | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **不是换皮塔防**   | 没玩过的人看完前 10 秒，说得出场上是「一群村里人」而不是「一堆塔」 | 录前 10 秒盲测。这是本版的头号验收                                                                                                                                                                       |
| **攒人有意思**    | 玩家说得出自己最想要笼子里的哪一个，以及为什么             | 直接问。答「都差不多」或者只说「那个数值高」即不通过——说明村民池是靠调参堆的                                                                                                                                                   |
| **进化看得见**    | 玩家能指着一个村民说出他现在几阶、身上多了什么             | 三阶立绘和攻击方式必须变。看不出来就说明进化只改了数值                                                                                                                                                               |
| **体验**       | 玩家能说出这一关是靠「谁 + 放在哪一路」过的             | 试玩后问「刚才这关是什么让你过的」。答案指向某个村民或某一路的排法即通过；答「等级够了」或「不知道」即不通过                                                                                                                                    |
| **克制不是惩罚**   | 被克的阵容仍能打过去，只是更慢；反过来光堆克制也不能当胜利按钮     | 回归 `护栏 2`：① 五个种子 = 五套随机喊到的人，运气最差那趟的通关率 **≥ 75%**，且都要在 60 天内推完 40 关；② 只用克制敌方主门路的人去打 8-5 **必须打不过**。倍率钉在 ×1.3 / ×0.77，往上调先看这两条                                                               |
| **辨识**       | 玩家能说出哪一路要崩，并且不把狗和鸡数成人               | 看 30 秒后问。说不清即上场人数或演出有问题；把小东西认成村民则是它们画得太大                                                                                                                                                  |
| **商业**       | 中位数 IPU ≥ 6，且次留不低于改动前               | 埋点看中位数，同时看「开战 ≥20 场的人里 IPU < 2 的占比」                                                                                                                                                       |
| **节奏**       | 卡关点落在每章后半段                          | 取代上一版「卡关点落在第 9–12 波」。太早挫败，太晚则复活广告没需求。**单个种子上测不准**（40 关做分母，墙落在第几关取决于成长曲线恰好停在哪儿），所以回归 `护栏 3` 分三条测：① 章内 `hpMul` 单调递增；② 每章第 1 关的总血量**比上一章第 5 关轻**（章间下探，形成锯齿）；③ 五个种子汇总，落在第 3 关及之后的墙占 **≥ 50%** |
| **布阵没被买掉**   | 村庄等级满级之后，「谁放哪一路」还是值钱的               | 回归 `护栏 1`：smart 布阵与 dumb 布阵的通关率差值 **≥ 25 个百分点**，且 dumb 自己不许过 60%。这条取代上一版的「smart 与 random 差值 > 2.5 波」。基线实测差值 **+52.5 ~ +67.5 点**，留了一倍余量——护栏抓的是机制被改坏，不是数值动了 2%                              |
| **每一笔都往上走**  | 买完只会更好打，不会更难                        | 回归：白板 / 半养成 / 满养成的通关率单调不降。满养成不许 ≥ 95%，得留下往后面关卡走的理由                                                                                                                                        |
| **随时有下一个目标** | 任何时候点开村子都不该是「齐了」                    | 看下一档目标是否返回 `done`。返回了就说明长线到头                                                                                                                                                              |


**最可能挂掉的是「不是换皮塔防」和「攒人有意思」这两条。** 它们挂了都不是调参能救的：第一条要回到 §1 与 §4.1，第二条要回到村民的定位设计——每个人必须有别人替不了的活。**注意这两条恰好是模拟器测不了的两条**，基线全绿不代表它们成立。

### 8.1 基线（2026-09-04，`npm run sim2`）

三条留空的阈值已经回填，依据是 `src/v2/` 的新模拟器：20 村民 × 三阶 × 星级 × 村庄等级 × 40 关全建模，五个种子跑 60 天。**产出用期望值不掷骰子**（方差对长线曲线没有信息量），**喊人掷骰子**（玩家选不了喊到谁，「手里正好没有克制这一章的门路」是真实处境）。


| 指标                 | 基线                        | 护栏阈值                  |
| ------------------ | ------------------------- | --------------------- |
| 40 关推完             | D28 ~ D46（五种子全部推完）        | 20 < D ≤ 50           |
| 村庄满级               | D22                       | 12 < D < 32           |
| smart 通关率          | 82.5% ~ 95%               | 最差种子 ≥ 75%            |
| 布阵差值（smart − dumb） | +52.5 ~ +67.5 点           | ≥ 25 点                |
| 判负原因               | 漏怪为主，超时 0% ~ 10%          | 超时 ≤ 12%，且汇总漏怪 > 汇总超时 |
| 星评分布               | ★3 50% ~ 71%，★2 25% ~ 50% | ★3 落在 35% ~ 85%       |


护栏在 `src/v2/__tests__/guardrails.test.ts`（25 条），跑 `npm test` 时和旧回归一起过。**它和 `src/formulas/__tests__/simulate.test.ts` 不互通**：旧的那 1751 行里有整整两组（`失败条件是队灭，不是漏怪` 10 条、`一个图不断出怪，不是十五场小仗` 10 条）是明文禁止本版做法的，它们钉的是旧引擎，会继续绿着直到旧引擎下线——别拿它的阈值判这一版。

**校准过程里挖出四个真 bug，都已在代码注释里写明「别改回去」**，因为它们全都是「看着合理、跑起来毁掉一条设计」的那类：

1. **扁平减法护甲造成免疫悬崖。** 铁柱 def 60，第 1~4 章每次只吃 1 点伤害（字面意义上无敌），第 8 章突然一下 214。更要紧的是它把判负也带歪了——前排打不死，敌人就永远堆在他面前过不去，于是没有漏怪、只有干等到超时。改成百分比减伤后超时率从 30% 掉到 5%。
2. **战场太长，后排永远打不到东西。** 原来 12 格长而射程只有 1~5，敌人被最前面的人挡在 pos 3.5，**cell 2 和 cell 3 打不到任何目标**，而布阵策略恰好把「打」位放在 cell 2。上场人数从 3 涨到 8 几乎没换来输出，第 6 章往后满级也推不动。压短战场后通关率 52.5% → 72.5%。
3. **出怪路线随波次轮转。** 哪怕每波只开一到两路，三波下来还是把三条路都用过了，玩家在只能上 3 个人时被迫覆盖全场（2-1 / 2-2 全种子失败）。改成按章给路数预算：1 章 1 路、2~4 章 2 路、5 章起 3 路。
4. **章内爬坡不许乘到攻击上。** 血量和只数吃满 ×1.85 是「要杀的更多」，玩家能靠布阵解决；攻击也吃满就变成「每章第 5 关必定把前排秒掉」，而前排一倒就漏怪判负，怎么排都没用。攻击的章内爬坡改吃平方根后，五个种子才全部推完 40 关——**在那之前削血量完全没用，因为瓶颈压根不在血量上**。

另外记两条**设计层面**的发现：

- **克制倍率 1.3 撑不起「为克制牺牲输出」，这是好事。** 布阵策略头一版给克制加了 60 分权重，在 8-5 上堆了一队攻击只有 0.85 倍的「挨得住」，34 只怪清不完漏 4 个判负，而随便换个排法反而 ★3 通关。说明克制不是解一次就完的谜题（§6 第 4 条），必须先配平定位。**因此 smart 不是上限**，护栏里的差值是「像样的排法 vs 乱来」，不是「最优 vs 乱来」。
- **星评原来没有区分度。** 只看「没漏 + 没倒」时 92%~97% 的通关都是 ★3——正常打赢本来就很干净，于是重打一关没有任何理由。加了 par 时间（最后一只出场 +14 秒）之后才分开：清干净是 ★2 的门槛，清得利索才是 ★3。
