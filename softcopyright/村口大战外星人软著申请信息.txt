1. 软件的主要功能（约 628 字，要求 500～1300）

本软件是运行于微信小游戏平台的村民收集与分路自动塔防类小游戏。玩家启动后进入加载界面，展示游戏名称、加载进度及《健康游戏忠告》；主包只带加载插画，出图后再拉取村口主界面分包，立绘、战斗图与背景音乐走 CDN 按需预热，避免开局把全部资源写入本地。加载完成后进入村口主界面。村口是全部功能的中枢，顶部常驻废铁、零件、工分与村庄经验四条资源，路上只站几个闲人。左侧弹弓摊、大喇叭杆、中间进度木牌、右侧图鉴墙、底部出村铁门。玩家进入弹弓摊消耗弹子，向下拉弹弓松手打靶，按权重掉落村庄经验、废铁、零件或工分；弹子按时间回复、通关补给，也可通过广告补充，弹子是次数不是货币。点击大喇叭花六工分喊人入伙，前四次必出新人，重复喊到的人折成废铁并加星，星级抬高手艺上限。点击图鉴查看二十名村民，按抗、打、治三种力筛选，只看书不喊人；对已入伙村民消耗废铁与零件提升手艺档位，手艺达到三档与六档时切换二阶与三阶立绘及攻击方式。村庄经验提升公共等级并解锁上场人数，最多十二人排满三路四格。点击铁门先进入章节路径，在 S 形土路上点墩选关，再进入布阵界面，玩家从底部坞把村民拎到格子上，开打后自动战斗。敌人从上方分路走进来，地面单位被本路最前排挡住，飞行单位点后排；漏三只到底线或超时判负，漏满可看广告复活。通关按漏怪、倒人和清场时间评一至三星，并发放废铁与弹子。主线八十章共四百关。进度采用本地存档，并与腾讯云 CloudBase 后端双向同步，按平台隔离账号并做版本冲突校验。

2. 软件的技术特点（约 96 字，要求不超过 100）

本软件基于微信小游戏，采用 TypeScript 与 PixiJS 实现。战斗规则与渲染分离，养成与关卡由数据表驱动；首屏分包、其余资源 CDN 按需加载；存档本地持久化并与云端乐观并发同步。


三、建议软件说明摘要

村口大战外星人是一款基于微信小游戏平台的村民收集与分路自动塔防类小游戏。外星人降落在县城，村口闲人翻出五金店和废品堆的破烂往身上焊，人手不够就去村委会大喇叭喊一嗓子再叫一个来。玩家在村口攒人、喂手艺，出村先看章节路径再排三路四格，开打后自动战斗；局外用弹弓摊拉弓打靶换资源。客户端采用 TypeScript 与 PixiJS 实现，首屏分包、其余资源 CDN 按需加载，战斗规则以确定性引擎与渲染层分离，后端基于腾讯云 CloudBase 实现平台登录、JWT 鉴权与存档同步。


四、内容规模（供填表与答复审查参考）

村民：20 人（5 门路 × 4 定位，方阵完整）
对外三种力：抗 / 打 / 治（对内挨拦打修）
每名村民视觉阶：3 阶，各有独立立绘与打法
手艺档位：1—75（视觉二三阶嵌在 3 / 6）
星级：★0—★10，管手艺上限
村庄等级：1—120（前 20 级手校）
上场人数：3—12（随村庄等级解锁，二十级站满）
关卡：80 章 × 5 关 = 400 关（前 8 章手写）
外星人类别：6 种（方块、小灰、铁罐、突击、飞碟、装甲）
战场：3 路 × 4 格 = 12 格
资源：废铁 / 零件 / 工分 / 村庄经验（4 种）；弹子是次数
弹弓摊靶位：6 种（铁皮罐、绿酒瓶、破电视、蓝塑料筐、吊铁盆、旧喇叭）
渲染场景：3 个（村子、章节路径、战场）
村子页面：5 个（home / horn / stall / folks / one）
浮层面板：加载 / 结算 / 复活 / GM
资源包：主包 Loading + 路图底图；分包 pkg-home / pkg-home-art；其余 CDN
云同步：cunkou-api（login / save/pull / save/push / health）
存档版本：REV = 3
