命名规则
--------
* 文件名必须与下面的清单完全一致（序号 + 业务名）。
* 扩展名 jpg / jpeg / png 都认，脚本按 stem 自动匹配，不用改脚本。
* 推荐竖屏实机截图（微信小游戏「真机调试」或手机内截图），保留完整游戏画面，
  不要裁掉顶部资源条和底部按钮 —— 审查看的就是这些 HUD 元素。
* 截图里不要出现微信胶囊按钮以外的系统悬浮窗、开发者工具面板、调试日志。
* 尚未截的图脚本会自动画「待补游戏截图」占位框，PDF 能照常生成，补图后重跑即可替换。

补图后重新生成

python3 "/Users/huyi/dk_proj/code_1/softcopyright/generate_softcopyright_doc_pdf.py"


清单（共 12 张，按游玩顺序；当前全部待补）
==========================================

01_loading.png — 图1  启动加载界面与健康游戏忠告
  加载底图 + 游戏名称「村口大战外星人」+ 进度条 + 底部《健康游戏忠告》全文。
  要点：忠告文字要能看清，这是版署必查项。启动后立刻截，别等跳村子。

02_home.png — 图2  村口主界面
  顶部废铁 / 零件 / 工分 / 村庄经验；路中间站着村民；左侧弹弓摊、中间关卡木牌
  与下一步目标、右侧图鉴墙、底部出村铁门。
  要点：四种资源数字别全是 0；铁门、摊子、图鉴墙尽量都在画面里。

03_stall.png — 图3  弹弓摊界面
  靶面（铁皮罐、酒瓶、破电视等）、剩余弹子、工分保底提示、广告补弹入口。
  要点：墙上最好挂着不止一种靶；弹子不是满仓也不是 0。

04_folks.png — 图4  村民图鉴
  已入伙彩色、未见过暗着；抗 / 打 / 治筛选；手艺档或星级标记；底部「喊一嗓子」。
  要点：要有一部分已入伙一部分没见过，对比明显。

05_one.png — 图5  单个村民三阶详情
  同一人一阶 / 二阶 / 三阶立绘并排，喂料按钮与下一档废铁、零件消耗。
  要点：三张立绘都要在，能看出身上多焊了东西；别只截一张大头。

06_call.png — 图6  喊人入伙反馈
  图鉴页点「喊一嗓子」之后的结果：新人入伙，或熟人加星。
  要点：能看清是谁来了、花了几个工分。新人回村口从右边走进来也可以截。

07_place.png — 图7  布阵界面
  3 路 × 4 格土路、底部坞里的待命村民、敌方主门路提示、开战按钮。
  要点：坞里有人、场上至少摆了几个；开战前截，别等自动打起来。

08_fight.png — 图8  战斗进行中
  外星人从上方走进来，村民自动出手；血条、漏怪计数、底线都在。
  要点：场上同时有村民和敌人；漏怪数不是 0 也可以，能看出底线在哪。

09_revive.png — 图9  漏怪复活弹窗
  漏满 3 只之后的复活界面：倒下的人、漏怪数、广告复活入口。
  要点：这是广告位，审查能看懂「看广告继续打」。打输一关才能截到。

10_settle.png — 图10  通关结算
  胜负结果、★☆ 星评、本关废铁与弹子、广告翻倍、下一关或回村口。
  要点：星评必须看得见（★★☆ 这种），不要只写「整挺好」。

11_stars.png — 图11  关卡木牌带星评
  回村口后，中间木牌上的关卡名 + ★★★ / ★★☆。
  要点：打过至少一关再截；能看出这关拿了几星。

12_goal.png — 图12  下一步目标
  村口「能喂 / 能喊 / 推图 / 打利索」木牌，点进去能跳到对应页。
  要点：木牌上那两三个字要能看清；和关卡木牌不是同一块。
